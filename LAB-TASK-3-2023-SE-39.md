# LAB TASK 3 - DIGITAL IMAGE PROCESSING

## Introduction

This document provides a comprehensive overview of the third lab task in the Digital Image Processing course. The task focuses on displaying RGB components, converting images to grayscale, and creating binary images.

## Objectives

- Read a colored image and display its Red, Green, and Blue components separately.
- Convert the image into Grayscale.
- Convert the Grayscale image into a Binary image.

## Input Image

- **Filename:** `Coin.jpg`

## Steps Involved

1. **Read the Image**: Use OpenCV to read the image file.
2. **Split RGB Channels**: Separate the image into its Red, Green, and Blue components.
3. **Convert to Grayscale**: Transform the colored image into a grayscale image.
4. **Thresholding**: Apply thresholding techniques to convert the grayscale image into a binary image.
5. **Display Results**: Use Matplotlib to display the original image, RGB components, grayscale image, and binary image.

## Conclusion

This lab task aims to provide practical experience in manipulating and analyzing images using various techniques in digital image processing. By completing this task, students will enhance their skills in image analysis and visualization.
